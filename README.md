# Lion Creatives — APERTURE review prototype

**This is a design-review prototype. It is not the Lion Creatives website and it is not production code.**

- All imagery is an **abstract placeholder**. No client work, client name, metric, testimonial or award appears anywhere — none is approved for use.
- Typography is a **provisional open-source stand-in** (Bricolage Grotesque, Archivo, Martian Mono). The premium system is not purchased.
- Pricing figures are **not approved** and are shown as structural placeholders only.
- Intentionally **unindexed**, but deliberately **crawlable** so reviewers and automated tools can read it.

The live Lion Creatives website is unaffected. This deployment is isolated from production DNS, forms, analytics and email.
