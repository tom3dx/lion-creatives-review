Lion Creatives · Typography decision package

System A vs System B — identical content, identical layout

The only variables are the display, body and mono families. Every measurement, colour, spacing value and string is identical on both sides, so any difference you see is typographic. System A is the current free system already running in V5. System B is a legally-usable stand-in for the premium direction — Anton, Space Grotesk and IBM Plex Mono — used to test the character of a tighter, heavier condensed display voice without licensing or embedding any commercial font file.
