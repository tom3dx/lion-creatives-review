Hubot Sans is retired. Each system below is rendered on the same real V8 moments — hero, a project headline beside a real frame, body copy, metadata, navigation, CTA, a photography heading, and a mobile hero — so the comparison is about the type, not the demo. All faces are properly licensed and free (Fontshare ITF / Google Fonts OFL); nothing here needs a purchase. Founder typography approval: PENDING.

Standing rule in every system: type sits beside or above media on its own ground — never across faces, never across film frames, never across UI screenshots.

Character: a sharp high-contrast serif with real edge — the most luxurious of the three, closest to fashion-editorial. Multiple weights give it hierarchy Instrument Serif can't offer.

Honest risk: can tilt the brand toward "fashion magazine" and away from "technology studio". The mono and General Sans pull it back, but the serif dominates first impressions.

Recommendation

System 01 (Editorial Cinema) is in the V8 build and is the recommendation: it is the only system where both halves of the company — cinema and engineering — are visible in the type itself. System 02 is the strongest alternative if the founder wants a more technological, less romantic register. System 03 is shown so the serif direction has a serious high-contrast option on the table, not to pad the deck.
